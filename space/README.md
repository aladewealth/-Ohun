Ohùn text-to-speech: Yoruba (own tone-aware voice, in training), Spanish, French, English. REST API under `/api`: `POST /api/v1/tts`, `GET /api/v1/voices`, docs at `/api/docs`. Spanish, French and English are live; Yoruba returns 503 until its weights are published at https://huggingface.co/aladewealth/ohun-yoruba. Source: https://github.com/aladewealth/-Ohun
